# Japanese Pokémon HOME Integration Ledger

This ledger tracks Japanese official Pokémon HOME material that directly affects **Pokémon Sword / Shield**. HOME is treated as a linked Generation VIII subsystem rather than a footnote because it changes transferability, move handling, gift workflows, Pokédex interoperability and cross-title behavior.

## Sword/Shield transfer rules currently confirmed by the official HOME site

Official Japanese HOME documentation states that:

- depositing and withdrawing Pokémon between Sword/Shield and HOME is a **Nintendo Switch version** feature;
- only Pokémon supported by Sword/Shield can be brought into Sword/Shield;
- move compatibility is handled per destination title rather than assuming a single permanent moveset across Generation VIII games;
- when a Pokémon is moved to another supported title, the destination title selects moves it can know at that Pokémon's level;
- when the Pokémon is returned to its original title, its original-title moves are restored;
- the official example explicitly uses a Sword/Shield Pikachu moved to BDSP and Legends: Arceus to illustrate title-specific move sets;
- Let's Go-origin Pokémon have additional special handling, including one-way restrictions after leaving Let's Go compatibility.

Primary page: https://www.pokemon.co.jp/ex/pokemonhome/ja/titles/sword_shield/

## Account and software-side rules

Official Japanese HOME instructions also state:

- Nintendo Account linkage is required for relevant shared functionality;
- Nintendo Switch Online membership is **not** required merely to use HOME;
- Switch and smartphone versions can share the same HOME boxes when linked to the same Nintendo Account;
- depositing/withdrawing Pokémon from Switch game save data is performed from the Switch version of HOME;
- the user selects both the linked software save data and the Switch user when accessing boxes.

Relevant official pages:

- https://www.pokemon.co.jp/ex/pokemonhome/ja/howto/
- https://www.pokemon.co.jp/ex/pokemonhome/ja/howto/01/

- BDSP/PLA cross-title movement restrictions and how SWSH-origin Pokémon are represented;
- PKHeX/HOME reverse-engineering evidence for remapped locations, moves and entity fields;
- changes introduced by later HOME versions that retroactively affect Generation VIII interoperability.

## Versioning rule

Current HOME web pages may describe modern behavior after later updates. They must **not** be projected backwards onto HOME 1.0 launch behavior without contemporaneous evidence. Historical notices and archived snapshots are required for version-specific claims.
