# Japanese Official Page Enumeration

This file is the page-by-page enumeration ledger for the Japanese official Sword/Shield web corpus. It is intentionally separate from the higher-level source index so that a single index URL cannot be mistaken for complete coverage.

## Discovery anchor

The official Sword/Shield news index reports **117 entries**, divided into **70 game-information entries** and **47 campaign entries**. The index spans the initial reveal through post-release online-service notices. Every entry must be individually resolved, classified, and reviewed before this family can be marked complete.

Index: https://www.pokemon.co.jp/ex/sword_shield/news/?category=information

## Unresolved / special-link cases already detected

The official index also contains entries whose link currently redirects, points to YouTube embeds, uses a removed external campaign destination, or failed retrieval. These are **not dropped**. They remain part of the 117-entry ledger and require archive/video-specific resolution.

Examples detected in the first pass include NEWS/PV YouTube entries, movie-distribution redirects, campaign microsites and several old embedded destinations that no longer resolve normally.

## Required fields for the final 117-entry table

Each official-news record will ultimately contain:

- official index date;
- exact Japanese title;
- direct URL or archived URL;
- original link type (official page / YouTube / external campaign / redirect);
- classification (`update`, `distribution`, `raid`, `competition`, `system`, `pokemon`, `character`, `product`, `campaign`, `video`, `other`);
- affected title (`Sword`, `Shield`, both, Expansion Pass);
- affected version/update where stated;
- Japan-only vs global/regional relevance;
- corresponding non-Japanese official pages when found;
- preservation status (`live`, `redirected`, `removed`, `archive located`, `archive pending`);
- research/verification notes.
